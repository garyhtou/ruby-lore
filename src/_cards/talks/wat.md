**"Wat"** is a four-minute lightning talk by Gary Bernhardt that pokes fun at the baffling corners of JavaScript and Ruby, punctuated by a deadpan "wat" at each absurd result. It is probably the single most-referenced talk in Ruby circles, and one of the most-shared tech talks ever made. If someone reacts to weird code with a slow "...wat," this is where it comes from. Watch it first, it is short and it is a rite of passage. ([Destroy All Software](https://www.destroyallsoftware.com/talks/wat))
