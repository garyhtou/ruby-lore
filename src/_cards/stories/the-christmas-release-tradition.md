Since the early days, nearly every major version of Ruby has shipped on **December 25**. It is a running gift-to-the-community joke that has quietly become a genuine tradition: Ruby 2.0, 2.1 through 2.7, and the big Ruby 3.0 all landed on Christmas Day. It is a small, warm ritual that tells you a lot about the culture, the language literally arrives as a present. ([ruby-lang.org release history](https://www.ruby-lang.org/en/downloads/releases/))
